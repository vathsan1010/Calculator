# 📱 Calculator

A modern, responsive calculator app built using **React**, **Vite**, and **Tailwind CSS**, featuring advanced functionalities like **drag-and-drop for swapping numbers and operators**.

---

## 🚀 Features

- Basic arithmetic operations: Addition, Subtraction, Multiplication, Division
- **Drag-and-Drop Support** to rearrange numbers/operators
- Responsive UI with Tailwind CSS
- State management using custom hooks
- Optimized build with Vite

## ⚙️ Installation

1. **Clone the repository:**  
   ```bash
   git clone https://github.com/your-username/vathsan1010-calculator.git
   cd vathsan1010-calculator
   ```

2. **Install dependencies:**  
   ```bash
   npm install
   ```

3. **Run the development server:**  
   ```bash
   npm run dev
   ```

4. **Build for production:**  
   ```bash
   npm run build
   ```
